# Full-Stack Web Development Mentorship Program
### For a 12-Year-Old Student — HTML/CSS + Basic JS → Advanced/Pro Level

**Schedule:** 3 classes/week, 1.5 hours/class (4.5 hrs/week)
**Total Duration:** ~37 weeks (≈ 9 months) | 111 classes | ~166 hours
**Starting point:** Solid HTML & CSS, beginner JavaScript
**End goal:** Can independently design, build, secure, and deploy a full-stack dynamic web application (JS + PHP + MySQL), with a bridge into modern frameworks (React)

---

## How This Program Is Structured

Each **Module** has a set number of weeks. Each week = 3 classes. Every module ends with a **mini-project** so concepts get used immediately, not just memorized. There are two **Capstone Projects** — one mid-program, one final — that are portfolio pieces.

### Mentor Notes (read before you start)
- **Keep every class hands-on.** At this age, 10 minutes of concept + 70 minutes of building beats 45 minutes of lecture. Explain just enough to unblock him, then let him type and break things.
- **Break every 25–30 minutes**, even briefly — attention span matters more than curriculum speed.
- **Let him make mistakes and debug them himself first.** Ask "what do you think is happening?" before giving the answer. Debugging skill is 50% of being a pro developer.
- **Gamify progress.** A visible checklist, streaks, or a "shipped projects" folder he can show off works well at this age.
- **Real projects, not toy examples.** Wherever possible, connect lessons to something he'd actually want to build (a game score tracker, a fan page, a homework planner, etc.)
- **Tools needed:** VS Code, Google Chrome (DevTools), Git + GitHub account, XAMPP or MAMP (Apache/PHP/MySQL local server), Node.js (installed before Module 13).

## PHASE 1 — Foundations & Tooling

### Module 0: Developer Environment & Workflow *(1 week / 3 classes)*
- **Class 1:** Professional VS Code setup — extensions (Prettier, Live Server, ESLint), folder structure conventions, keyboard shortcuts
- **Class 2:** Command line basics — `cd`, `ls`/`dir`, `mkdir`, `touch`, running a local server
- **Class 3:** Git & GitHub — what version control is and why every pro uses it; create first repo, `git init/add/commit/push`
- ✅ **Checkpoint:** His existing HTML/CSS site pushed to GitHub

---

## PHASE 2 — JavaScript Mastery

### Module 1: JavaScript Core Refresh *(3 weeks / 9 classes)*
- Variables (`let`/`const`), data types, type coercion
- Operators, conditionals (`if/else`, `switch`), ternary operator
- Loops (`for`, `while`, `for...of`, `for...in`)
- Functions — declarations, expressions, arrow functions, default parameters
- Arrays & array methods (`push`, `pop`, `slice`, `splice`, basic iteration)
- Objects — properties, methods, `this` (intro)
- **Mini-project:** Number guessing game / rock-paper-scissors

### Module 2: DOM & Events *(2 weeks / 6 classes)*
- Selecting elements (`querySelector`, `getElementById`)
- Manipulating DOM — text, attributes, classes, creating/removing elements
- Event listeners (click, submit, keypress, input)
- Forms & validation with JS
- **Mini-project:** To-do list app with add/delete/complete + local storage

### Module 3: Advanced JavaScript *(3 weeks / 9 classes)*
- ES6+ features: destructuring, spread/rest operators, template literals, modules (`import`/`export`)
- Higher-order functions: `map`, `filter`, `reduce`, `forEach`
- Closures & scope deep dive
- `this` keyword in depth, `bind`/`call`/`apply`
- Classes & OOP in JavaScript (constructors, inheritance, `extends`)
- Asynchronous JS: callbacks → Promises → `async`/`await`
- `fetch()` API — getting data from the internet, working with JSON
- Error handling (`try/catch`)
- **Mini-project:** Weather app or quote generator using a public API

---

## PHASE 3 — Advanced Styling & Version Control

### Module 4: Advanced CSS *(2 weeks / 6 classes)*
- Flexbox & CSS Grid mastery (real layouts, not just theory)
- Responsive design & media queries, mobile-first approach
- CSS variables & custom properties
- Transitions & animations
- Intro to Sass/SCSS (nesting, variables, mixins)
- BEM naming methodology for clean, scalable CSS
- **Mini-project:** Fully responsive portfolio landing page

### Module 5: Git & GitHub — Collaboration Level *(1 week / 3 classes)*
- Branching & merging
- Pull requests, resolving merge conflicts
- `.gitignore`, README best practices
- Deploying a static site via GitHub Pages
- ✅ **Checkpoint:** Portfolio site live on the internet

---

## PHASE 4 — Backend Development with PHP

### Module 6: Backend Fundamentals & PHP Basics *(3 weeks / 9 classes)*
- Client-server model — how the web *actually* works (request/response, front-end vs back-end)
- PHP syntax, variables, echo/print, comments
- Control structures & functions in PHP
- Arrays in PHP (indexed & associative)
- Handling form data — `$_GET`, `$_POST`, `$_REQUEST`
- Working with files (`include`, `require`)
- **Mini-project:** Simple contact form that processes and displays submitted data

### Module 7: PHP Intermediate + OOP *(3 weeks / 9 classes)*
- Sessions & cookies (remembering users across pages)
- Object-Oriented PHP: classes, objects, constructors, properties, methods
- Inheritance & interfaces (intro level)
- Input validation & basic sanitization
- Error handling & exceptions
- **Mini-project:** Simple visitor counter / "remember me" mini app using sessions

---

## PHASE 5 — Databases

### Module 8: SQL & MySQL Fundamentals *(3 weeks / 9 classes)*
- What a database is; relational database concepts (tables, rows, columns)
- Installing/using phpMyAdmin via XAMPP/MAMP
- SQL: `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- Filtering & sorting: `WHERE`, `ORDER BY`, `LIMIT`
- Relationships: primary keys, foreign keys, basic `JOIN`
- Designing a simple database schema (tables + relationships on paper first)
- **Mini-project:** Design & build a database for a "student grade tracker" or "game collection"

### Module 9: PHP + MySQL Integration *(3 weeks / 9 classes)*
- Connecting PHP to MySQL using **PDO** (the professional standard)
- Full CRUD (Create, Read, Update, Delete) from a web page
- **Prepared statements** — preventing SQL injection (critical habit to build early)
- Building a login/register system with **password hashing** (`password_hash`, `password_verify`)
- **Mini-project:** A working login system + a simple dynamic blog (posts stored in DB, shown on page)

---

## PHASE 6 — Capstone I

### Module 10: Capstone Project 1 — Full Dynamic Website *(2 weeks / 6 classes)*
Student plans, designs, and builds a complete CRUD web app end-to-end:
- Examples: personal blog with admin panel, task manager, mini forum, game-review site
- Must include: front-end (HTML/CSS/JS), PHP backend, MySQL database, login system
- Deployed and demoed like a real project
- ✅ **Checkpoint / Portfolio Piece #1**

---

## PHASE 7 — Connecting Front-End & Back-End Like a Pro

### Module 11: APIs, JSON & AJAX *(2 weeks / 6 classes)*
- Building a simple REST API with PHP (returning JSON)
- Consuming your own API from JavaScript using `fetch()`
- AJAX-style pages — updating parts of a page without reloading
- **Mini-project:** Convert a page from Module 10 into an AJAX-powered page (e.g., add comments without refreshing)

### Module 12: Security & Professional Best Practices *(1 week / 3 classes)*
- Common vulnerabilities explained simply: SQL injection, XSS, CSRF
- Why prepared statements & sanitization matter (reinforced with real examples)
- HTTPS, environment variables, keeping credentials out of code
- Clean code habits: naming, comments, consistent formatting
- ✅ **Checkpoint:** Security audit of his own Capstone 1 project — find and fix issues

---

## PHASE 8 — Modern Front-End (Bridge to Frameworks)

### Module 13: Introduction to React *(4 weeks / 12 classes)*
- Why frameworks exist; component-based thinking
- JSX syntax, functional components, props
- State with `useState`, side effects with `useEffect`
- Building a small multi-component app
- Connecting a React front-end to a PHP API (fetching real data from his own backend)
- **Mini-project:** Rebuild the to-do list or blog front-end in React, powered by the PHP API from Module 11

---

## PHASE 9 — Deployment & Final Capstone

### Module 14: Deployment & Going Live *(1 week / 3 classes)*
- Domains & hosting explained
- Deploying a PHP/MySQL app to real hosting (or a free-tier service)
- Environment configuration for production vs local
- Basic performance checks (image sizes, load time, caching intro)

### Module 15: Capstone Project 2 — Pro-Level Full-Stack App *(3 weeks / 9 classes)*
The big finale — student designs and ships an original, portfolio-ready full-stack application combining everything:
- Front-end (HTML/CSS/JS, optionally React)
- PHP backend with a REST-style API
- MySQL database with proper relationships
- Authentication, security best practices, deployed live
- **Demo Day:** He presents and explains his own project — the mark of a real developer, not just someone who followed a tutorial

---

## Suggested Milestone Rewards
Consider small recognitions at each ✅ Checkpoint (Module 0, 5, 10, 12, 15) — kids stay far more motivated with visible wins along a 9-month journey than with a single reward at the very end.

## Optional Next Steps (after this program)
Once completed, natural next directions include: Node.js/Express (JS on the backend), TypeScript, more advanced React (routing, context/state libraries), or mobile app development (React Native) — all of which build directly on this foundation.
