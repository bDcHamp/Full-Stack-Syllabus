Course Introduction

Full-Stack Web Development

A comprehensive ~37-week mentorship program taking you from solid HTML/CSS fundamentals to designing, securing, and deploying complete full-stack web applications.

Duration ~37 Weeks ≈ 9 months
Schedule 3 Classes / Wk 1.5 hrs per class (111 classes)
Structure 9 Phases 16 Modules total
Output 2 Capstones 5 Milestone Checkpoints

Program Methodology

70% Hands-On Building

10 minutes of conceptual foundation followed by 70 minutes of direct typing, experimentation, and problem solving.

Self-Directed Debugging

Learn to read error logs, inspect network traffic, and diagnose bugs independently—the cornerstone of professional engineering.

Production Workflows

Build with industry tools: Git version control, command line, PDO prepared statements, and live cloud deployment.

Milestone Driven

Track tangible progress after each module with working applications and live code repositories.
